# Sokudo-Oni
Repositorio open-source con ejemplos para la placa Sokudo Oni, un sistema de control para robots velocistas basado en la Baby Orangutan. Incluye pruebas de hardware, demostraciones, plantillas de control y ejemplos listos para correr en Arduino. Pensado para estudiantes, makers y competidores de robótica móvil.


# Sokudo Oni – Ejemplos para Baby Orangutan

Este repositorio contiene códigos de ejemplo para la placa **Sokudo Oni**, utilizada en robots velocistas, basada en el controlador **Pololu Baby Orangutan**.

## Contenido

### Ejemplos
- **Blink** — Probar LED.
- **Botón** — Lectura de los botones integrados.
- **GO** — Lectura del pin de inicio de carrera.
- **Sensores** — Lectura de sensores IR/reflectancia.
- **Motores** — Pruebas básicas de movimiento.
- **Seguidor de línea básico** — Control mínimo PID proporcional.

## Librerías necesarias
- Pololu Orangutan (incluye:
  - OrangutanMotors
  - OrangutanAnalog
  - OrangutanPushbuttons
)

## Hardware
Incluye pinout e información relevante de la placa Sokudo Oni.
